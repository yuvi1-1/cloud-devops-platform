# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/yuvi1-1/cloud-devops-platform/security/advisories/new)
with steps to reproduce and the affected component. You will get an acknowledgement within 72 hours.

## Supported versions

Only the latest release on `main` receives fixes.

## How this project handles security

See [docs/security.md](docs/security.md) for the threat model, controls and accepted risks.
